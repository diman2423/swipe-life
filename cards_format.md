# Как писать карточки

Карточки лежат в `cards.js`. Открой его любым редактором, скопируй похожую карточку, поменяй поля, сохрани и обнови страницу.

> Почему `.js`, а не `.json`: браузер не даёт странице читать `.json` с диска, если открыть `index.html` двойным кликом. Внутри всё равно обычный JSON-массив, к первой строке `window.CARDS =` просто не прикасайся.

## Минимальная карточка

```json
{
  "id": "boss_weekend",
  "who": "Начальник", "face": "👔",
  "text": "Возьмёшь проект на выходных? Заплачу сверху.",
  "left":  { "label": "Нет, у меня жизнь", "fx": { "work": -8, "love": 5 } },
  "right": { "label": "Да, давай", "fx": { "money": 10, "health": -5 } }
}
```

| Поле | Что это |
|---|---|
| `id` | Уникальное имя латиницей. По нему карточки ссылаются друг на друга |
| `who`, `face` | Имя персонажа и эмодзи на карточке |
| `text` | Вопрос/ситуация над карточкой |
| `left`, `right` | Варианты при свайпе влево и вправо |
| `label` | Подпись варианта, видна при перетаскивании |
| `fx` | Как меняются шкалы: `money` 💰, `health` ❤️, `love` 💞, `work` 💼. Числа ±, шкалы 0–100 |

Не забывай запятые между карточками и между полями: это JSON.

## Что ещё умеет карточка

| Поле | Где | Пример | Что делает |
|---|---|---|---|
| `if` | карточка | `"if": { "health": [0, 30] }` | Выпадает только когда ❤️ от 0 до 30 |
| `if.flags` | карточка | `"if": { "flags": ["partner"] }` | Только если флаг есть |
| `if.notFlags` | карточка | `"if": { "notFlags": ["credit"] }` | Только если флага нет |
| `weight` | карточка | `"weight": 3` | Как часто выпадает. По умолчанию 1, больше — чаще, 0.5 — вдвое реже |
| `once` | карточка | `"once": true` | За забег выпадает максимум один раз |
| `chainOnly` | карточка | `"chainOnly": true` | Сама не выпадает, только по цепочке через `then` |
| `set` | вариант | `"set": ["credit"]` | Ставит флаги |
| `unset` | вариант | `"unset": ["credit"]` | Снимает флаги |
| `then` | вариант | `"then": { "card": "bank_payment", "in": 10 }` | Через 10 недель придёт карточка `bank_payment` |
| `then` со списком | вариант | `"then": { "card": ["stocks_up", "stocks_down"], "in": 10 }` | Через 10 недель придёт одна из карточек, случайно |

Флаги — это просто метки-слова, придумывай любые: `credit`, `partner`, `has_dog`.

Один флаг служебный: **`has_flat`** — стоит, пока у игрока есть квартира. Его можно использовать в `if` (например, ЖКХ только владельцам, хозяйка-арендодатель только без квартиры), но ставить или снимать его через `set`/`unset` бесполезно — игра выставляет его сама. Условия можно сочетать: `"if": { "money": [0, 20], "flags": ["credit"] }`.

## Пример цепочки

Кредитка в `cards.js`: `bank_credit` → «Оформить» ставит флаг `credit` и через 10 недель вызывает `bank_payment`. Там «Минималку» снова вызывает `bank_payment` через 6 недель (долг тянется), а «Закрыть весь» снимает флаг. Пока флаг стоит, `bank_credit` не выпадает.

## Если ошибся

При открытии страницы карточки проверяются. Если что-то не так (нет `id`, опечатка в шкале, `then` ведёт на несуществующую карточку), внизу экрана появится красная строка с объяснением. Если страница вообще пустая — скорее всего, сломан JSON (лишняя или пропущенная запятая, кавычка). Открой `index.html?debug`: там видны id карточки, флаги и очередь цепочек.
