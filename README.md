# Свайп-жизнь

Reigns про жизнь и деньги. Свайпай решения влево или вправо и держи четыре шкалы — 💰 Деньги, ❤️ Здоровье, 💞 Отношения, 💼 Дело — подальше и от нуля, и от сотни.

Фишка: у квартиры нет видимой цены. Сколько она стоит на самом деле, узнаешь только в момент сделки.

**Играть:** открыть `index.html` в браузере (сервер не нужен) или по ссылке GitHub Pages.

## Устройство

- `index.html`, `style.css`, `js/` — игра на чистом HTML/JS, без сборки.
- `cards.js` — все карточки; формат в `cards_format.md`, читаемый список — `cards_review.md`.
- `js/realty.js` — квартира, скрытая цена и сделки.
- `tools/simulate.js` — бот-симулятор баланса: `node tools/simulate.js`.
- `tools/cards_review.js` — пересобрать `cards_review.md`.
- `SPEC.md` — спека игры, `backlog.md` — задачи, `CHANGELOG.md` — изменения.

Отладка: `index.html?debug` — видны числа шкал и скрытая цена; R — продать, O — оценщик, B — продавец. `?noflat` — старт без квартиры.
